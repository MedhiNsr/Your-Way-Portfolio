# Security and privacy notes

This repository is a portfolio snapshot of **Your Way**. It has a fresh Git history and is kept separate from the original project repository.

## Data scope in this snapshot

- No user account or sign-in flow is included.
- Route origins and destinations are used in memory to request route calculations from the configured providers; the application does not save route history.
- Personal tunnel notes and a tunnel-memory journal are not included in this snapshot.
- Comfort preferences are stored in the user's browser.

Do not enter real personal addresses when demonstrating this project. Routing requests require sending route inputs to the configured routing providers.

## Configuration

- Keep API keys and environment-specific values out of Git.
- Use local environment variables for development.
- Commit only placeholder examples where configuration documentation is needed.
- Review files and Git history before changing the visibility of this repository.

## Reporting

For a security concern, contact the repository owner privately through GitHub.
