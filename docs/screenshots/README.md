# Portfolio Screenshots

This folder is reserved for product screenshots used in the public portfolio / README.

No screenshots are committed yet because they should be captured from the working application rather than mocked.

## Recommended screenshots

Capture these views from the current working version:

1. **Home / route preparation**
   - origin and destination
   - comfort preferences
   - clean full-page view

2. **Route analysis**
   - map visible
   - detected tunnels visible
   - route comparison visible

3. **Tunnel detail / confidence**
   - tunnel length
   - estimated crossing time
   - confidence or verification messaging

4. **Alternative route comparison**
   - fastest route versus lower-tunnel-exposure option

5. **Comfort preferences**
   - only if the view contains no sensitive personal data

## Screenshot rules

- use the current working product
- remove or blur personal addresses and user data
- do not expose API keys, tokens or internal identifiers
- use realistic but non-sensitive example routes
- keep browser chrome minimal
- prefer 16:9 or wide desktop captures
- do not edit screenshots in a way that misrepresents the product

Once captured, suggested filenames are:

```text
01-home.png
02-route-analysis.png
03-tunnel-confidence.png
04-route-comparison.png
05-preferences.png
```
